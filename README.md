# Meta Guitar tabs

Every `.txt` file here shows up as a song in Meta Guitar (it checks this repo each time the app opens).
Optional first lines set the song up:

```
Title: Quizas
Artist: Osvaldo Farrés
BPM: 70
Beats: 4
Timing: fixed 3
```

Then the ASCII tab (`e|---0---|` lines). Delete a file to remove the song.
